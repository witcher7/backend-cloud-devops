# Core api groups vs named api group 
# core api groups are the main core components of kubernetes 
apiVersion : v1 
kind: Pod 
metadata: 
  name: task-web 

# Named Api groups are all of the new controllers and operators that are created came later release after core api's
apiVersion: networking.k8s.io/v1 
kind: NetworkPolicy 
metadata:
  name: projectx_policy 
  namespace: default 

## namespaces
In kubernetes namespaces provides a mechanism for isolating groups of resources 
within a signle cluster. Names of resources need to be unique within a namespace, 
but not across namespaces. Namespace-based scoping is applicable only for namespaced 
objects(eg Deployment, services etc) and not for cluster-wide objects(storageclass , pv etc)

kubectl create namespace test1
kubectl create namespace test2

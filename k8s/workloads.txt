## namespaces
In kubernetes namespaces provides a mechanism for isolating groups of resources 
within a signle cluster. Names of resources need to be unique within a namespace, 
but not across namespaces. Namespace-based scoping is applicable only for namespaced 
objects(eg Deployment, services etc) and not for cluster-wide objects(storageclass , pv etc)

 ## Blue green environment means staging and production 
 Initial state(blue) --> current ,stable version handling all live user traffic
 Deploy new Version(Green) --> new version of the application(the "green" env) is deployed in paralled, with it's own 
 set of pods and different label --> isolated and does not receive live traffic allowing for testing 


 ## ROLLING UPDATE helps to use update method effeciently when we are updating out deployment so it will kill one by one and replace the pod
 then kill another and replace so that customers wont face issues while updating 

 apiVersion: apps/v1 
 metadata:
    name: nginx-deployment 
 spec: 
   selector:  
      matchLabels:
        app: nginxdeployment 
   revisionHistoryLimit: 3  # tells how many old replicaSets to keep after update  .. allow rollback if new version fails

     type: RollingUpdate
